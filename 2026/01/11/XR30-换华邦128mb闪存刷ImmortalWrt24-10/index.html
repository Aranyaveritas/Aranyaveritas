    XR30 换华邦 128mb Winbond W25N01GVZEIG

    前置救砖

    • 拆取原有的兆易创新 GD5F1GM7UE 换为 Winbond W25N01GVZEIG 1Gb NAND Flash 3.3v
    • 保存有原厂cmcc备份 tmp 的 preloader.nand.bl2 和 Factory
    • 在你电脑主机插入一根网线备用，后续刷完连接设备，修改网关ipv4地址等

    路由器断电，使用 USB转TTL（建议使用3.3V电平的）连接路由器TTL接口。
    运行“打开设备管理器命令.bat”在设备管理器查看USB转TTL对应的COM口号。这个COM口不能被其他程序占用。
    CH340
    GND-GND
    RX-Tx
    TX-Rx
    3.3[vcc]不接

    Xshell 工具内新建会话 新建会话->连接->串口对应 COM x / 波特率 115200

    将Xshell断开[取消占用端口] 新建一个本地会话

    在XR30\MT798XTTL文件夹内右键此处终端

    手动运行mtk_uartboot命令，详见mtk_uartboot文件夹里的教程。COM x <对应COM端口>
    fib.bin对应你放置在mtk_uartboot中的 mt7981_cmcc_xr30-fip-fixed-parts.bin文件，修改名字为fib.bin

    .\mtk_uartboot.exe -s COM3 -p .\mt7981\mt7981-ddr4-bl2.bin -a -f fip.bin –brom-load-baudrate 115200 –bl2-load-baudrate 115200

    1.运行命令后会出现等待握手信息：

    mtk_uartboot - 0.1.1
    Using serial port: COM3
    Handshake…

    2.然后路由器上电开机，握手成功CMD会输出sending payload信息开始发送bl2：

    hw code: 0x7986
    hw sub code: 0x8a00
    hw ver: 0xca01
    sw ver: 0x1
    Baud rate set to 115200
    sending payload to 0x201000…

    3.发送完成加载bl2会输出信息同时开始发送fip：

    Checksum: 0x3c82
    Setting baudrate back to 115200
    Jumping to 0x201000 in aarch64…
    Waiting for BL2. Message below:

    ==================================

    NOTICE: BL2: v2.10.0 (release):v2.4-rc0-5845-gbacca82a8-dirty
    NOTICE: BL2: Built : 20:30:05, Feb 2 2024
    NOTICE: WDT: Cold boot
    NOTICE: WDT: disabled
    NOTICE: CPU: MT7986 (2000MHz)
    NOTICE: EMI: Using DDR4 settings
    NOTICE: EMI: Detected DRAM size: 1024MB
    NOTICE: EMI: complex R/W mem test passed
    NOTICE: Starting UART download handshake …

    ==================================

    BL2 UART DL version: 0x10
    Baudrate set to: 115200

    此时在上传fip，600KB的fip使用1500000波特率只需要几秒钟，低波特率则大概45秒。
    此时如果需要进入uboot webui可以直接按住reset按键不放，等待uboot指示灯闪烁并进入uboot。
    如果没有按reset会直接启动固件，进入固件再恢复刷砖的分区也行。

    4.fip加载完后输出：

    FIP sent.

    ==================================

    NOTICE: Received FIP 0x90b59 @ 0x40400000 …

    ==================================

    此时程序已经执行完，已经加载uboot，如果没有按reset会直接启动固件，按reset就进入uboot webui恢复刷砖的文件。

    在Xshell中点击之前的端口会话 然后窗口内回车，查看是否变为MT7981> XR30 端口监控同时长按reset键 [网口上方] 10秒，然后将连接电脑主机的网线另一端插入任意 LAN

    路由器默认uboot是192.168.1.1 将你的设备连接的这个新以太网接入
    属性 ip 设为手动 设备ipv4 : 192.168.1.2 ,子网前缀 24 ，网关是 192.168.1.1

    Uboot WebUI 救砖
    长按 reset 插电，直至 LED 闪过，电脑插线手动设置 ip 为 192.168.1.x，浏览器访问 Uboot
    更新 Uboot 固件：http://192.168.1.1/uboot.html 后 会重启 断电断网重复以上刷入操作后续在webui界面上传bl2
    更新 BL2 固件：http://192.168.1.1/bl2.html 后断电 先按reset键，在上电等待灯闪烁或不闪几次变白色，设置同网段，
    更新系统固件：http://192.168.1.1 上传 immortalwrt-mediatek-mt7981-cmcc_xr30-squashfs-factory.> bin 上传完后，自动重启 同网页会进入系统，将主机ip改为自动获取

    • 确保已刷入 ImmortalWRT 并能正常启动
    • 准备好两个备份文件：
      preloader.nand.bl2 - 原厂BL2引导程序
      Factory.bin - 原厂无线校准数据

    登录ImmortalWRT并开启SSH

    浏览器访问 192.168.1.1 设置密码后
    系统 → 管理权 → SSH访问 → 启用
    在Xshell中新建会话ssh连接，用户名root 密码xxx连接到后，将原厂的两个文件放置在/tmp/tmp中

    查看当前分区信息**

    cat /proc/mtd

    你应该看到类似这样的输出：
    dev: size erasesize name
    mtd0: 08000000 00020000 “spi0.0”
    mtd1: 00100000 00020000 “BL2”
    mtd2: 00080000 00020000 “u-boot-env”
    mtd3: 00200000 00020000 “Factory”
    mtd4: 00200000 00020000 “FIP”
    mtd5: 07200000 00020000 “ubi”

    刷写恢复原厂BL2分区（mtd0）

    mtd write /tmp/tmp/preloader.nand.bl2 bl2

    恢复原厂Factory

    mtd write /tmp/tmp/Factory.bin factory

    重启路由器

    reboot
    此系统更新的系统固件：immortalwrt-mediatek-mt7981-cmcc_xr30-squashfs-factory
    后续更新为：immortalwrt-mediatek-filogic-cmcc_xr30-nand-squashfs-sysupgrade
